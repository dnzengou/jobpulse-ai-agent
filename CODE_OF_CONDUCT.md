# Code of Conduct

## Our standard

JobPulse AI Agent is built by and for job seekers. People show up at different points in their careers, from different industries, in different circumstances. We want the project to be useful to all of them.

We expect everyone who participates — in issues, pull requests, discussions, the Discord, or any other project space — to treat others with respect.

**Do:**

- Assume good faith. Ask clarifying questions before assuming someone meant the worst.
- Be specific. "This bullet is misleading because the code does X not Y" is a useful review comment; "this is bad" is not.
- Credit prior work. If your idea builds on someone else's issue or PR, link it.
- Let people opt out of a thread. "I don't have bandwidth for this right now" is a complete sentence.

**Don't:**

- Harass, demean, or threaten anyone, in public or in private, in any project space.
- Post sensitive personal information (yours or anyone else's) in issues or PRs. If you need to share a resume to reproduce a bug, redact it first.
- Use the project as a platform for political campaigning or recruitment unrelated to its goals.

## Scope

This code applies to all project spaces — this repository, the Discord, the landing page's contact channels — and to public spaces when someone is representing JobPulse (e.g. in a talk, podcast, or blog post that uses the project's name).

## Enforcement

Report incidents to the maintainer via:

- A [private GitHub security advisory](https://github.com/dnzengou/jobpulse-ai-agent/security/advisories/new) (even for non-security conduct issues — it's the private channel we have).
- Discord DM to the maintainer.

Reports are confidential. We will acknowledge within a reasonable time, investigate, and respond with one of: no action needed; private warning; temporary ban from project spaces; permanent ban. We will not disclose the reporter's identity to the subject of the report without the reporter's consent.

## Attribution

This code of conduct borrows from [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in spirit but intentionally keeps things short so it's actually read.
