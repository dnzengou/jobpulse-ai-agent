How it works

From zero to application package
in one session

Type /findmeajob and let the agent handle the rest.

1

Tell it what you want

Role, location, remote preference, salary range, experience level. One question at a time, conversational — not a form dump.

2

Deep multi-query search

Generates 5–7 search variations from your profile, runs them in parallel across 8 job boards, dedupes 300+ results down to a scored shortlist.

3

Company research

For each job you select, a dedicated agent browses the company website, Glassdoor, LinkedIn, Crunchbase, and GitHub. Red flags, green flags, culture signals — all in one structured brief.

4

Application package built automatically

Customized resume (re-keyed to the JD, not fabricated), targeted 3-paragraph cover letter, interview prep guide with STAR outlines — all saved locally, ready to review.

5

Browser-assisted apply (optional)

Say "apply to Acme Corp" and the agent opens the form, fills it field by field with your confirmation, and submits only when you say the word. Sensitive fields always flagged to you.

Features

Everything you need,
nothing you don't

🔍

Multi-board search

Indeed, LinkedIn, Glassdoor, ZipRecruiter, Google Jobs, Bayt, Naukri, BDJobs — in one command.

Smart scoring

Domain-aware scorer ranks by AI/stack/seniority/salary signals. Noise filtered before you see it.

Resume review + build

Score your existing resume or build one from scratch. Follows real formatting and content standards — no fluff.

Company research

Full research brief: culture signals, tech stack, funding status, red/green flags, and customization notes for your resume.

✍️

Cover letter writer

3-paragraph, 200–280 words, company-specific opener, real numbers from your resume. No clichés.

🎤

Interview prep

Behavioral questions with STAR outlines drawn from your actual experience. Technical questions, and smart questions to ask them.

🌐

Browser-assisted apply

Navigate, fill, and submit application forms with your AI agent — one confirmation at a time. You're always in control.

🔒

100% local data

All resumes, research, and preferences stay on your machine in job-search/. No telemetry, no cloud sync.

Install

Up and running in 60 seconds

Requires Claude Code, Python ≥ 3.10, and Node.js ≥ 18.

Plugin marketplace
Manual
/plugin marketplace add JCodesMore/jcodesmore-plugins
/plugin install jobs-for-ai-agents@jcodesmore-plugins
# Restart Claude Code, then:
/findmeajob

Or clone and run directly: git clone https://github.com/dnzengou/jobpulse-ai-agent.git && claude --plugin-dir jobpulse-ai-agent
